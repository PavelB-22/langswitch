# Spec 002: Автопереключение, исправления и окно настроек

## Зачем
У Caramba главная фишка — исправлять раскладку **самой**, без нажатий. Плюс у неё есть окно, где всё включается/выключается. Делаем то же у себя.

## Сценарии

### US5 (P1) — Автопереключение на лету
- Дано: включена EN, набираю «ghbdtn». Когда: жму пробел. Тогда: в тексте «привет », раскладка RU.
- Дано: включена RU, набираю «руддщ». Когда: пробел. Тогда: «hello », раскладка EN.
- Дано: слово правильное («hello» в EN). Тогда: ничего не трогаем.
- Дано: слово непонятно в обеих раскладках («GPT», «qwe»). Тогда: ничего не трогаем.
- Дано: программа исправила, а я не хотел. Когда: сразу двойной Shift. Тогда: вернулось как было, и это слово больше не исправляется до перезапуска.

### US6 (P2) — Исправление регистра
- «ПРивет» → «Привет» (две заглавные в начале).
- «пРИВЕТ» → «Привет» (случайный Caps Lock).
- Аббревиатуры «США», «NASA» не трогаем.

### US7 (P3) — Исправление опечаток (по умолчанию выключено)
- «превет» → «привет» по словарю macOS. Только слова от 4 букв.

### US8 (P1) — Окно настроек
Вкладки: **Основные** (вкл/выкл программу, двойной Shift, чувствительность двойного Shift, автозапуск, статус разрешения), **Исправления** (автопереключение, регистр, опечатки), **О программе**.
- Открывается из меню значка «Настройки…» (⌘,).
- Изменения применяются сразу, без перезапуска, и сохраняются.

## Граничные случаи
- Поле пароля → никаких исправлений.
- Слова из 1 буквы, с цифрами, ссылки/почта (есть «@», «/», «:») → не трогаем.
- Enter не исправляет (чтобы не сломать отправку сообщений) — только пробел.

## Требования
- FR-101 Проверять слова встроенным словарём macOS (NSSpellChecker) для ru и en, без интернета.
- FR-102 Исправлять по пробелу: пробел перехватывается, слово заменяется, пробел печатается после.
- FR-103 Двойной Shift сразу после автоисправления — откат + игнор слова до перезапуска.
- FR-104 Все функции — галочки в настройках, хранятся в UserDefaults.
- FR-105 Окно настроек на SwiftUI с вкладками, поддерживает тёмную тему.

## Критерии успеха
- «ghbdtn», «vfvf», «rfr ltkf» исправляются автоматически; «hello», «привет», «GPT», «iPhone» — нет.
- Откат двойным Shift работает в 10/10.
- Галочки в настройках реально выключают функции.
