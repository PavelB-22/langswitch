# Spec 003: LangSwitch на GitHub
- US1: человек ставит LangSwitch одной строкой из Терминала, без xattr и ручного копирования.
- US2: Павел выпускает версию командой `bash publish.sh` (сам поднимает номер, спрашивает «что нового»).
- US3: после обновления «Универсальный доступ» не слетает (подпись постоянным сертификатом Shepot Self-Signed).
- Ограничения: только Mac (macOS 13+), автообновления внутри программы пока нет — обновление той же командой.
