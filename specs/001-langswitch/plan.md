# Plan: LangSwitch

## Как строим
- **Язык:** Swift, AppKit. Приложение без окна в Dock (`LSUIElement`), только иконка в строке меню.
- **Ловим клавиши:** системный «перехватчик событий» `CGEventTap` (слушает клавиатуру во всех программах). Требует разрешения «Универсальный доступ» (Accessibility).
- **Двойной Shift:** следим за событием `flagsChanged`. Shift нажат → отпущен → снова нажат и отпущен за ≤ 0,3 с, без других клавиш между — это жест.
- **Смена языка:** системный API Text Input Sources (`TISSelectInputSource`). Ищем раскладки с языком `ru` и `en`.
- **Последнее слово:** храним в памяти буквы с момента последнего пробела/Enter/клика/смены приложения. Исправление: шлём Backspace × длина слова, меняем язык, печатаем новое слово через `CGEvent` с `keyboardSetUnicodeString`.
- **Выделение:** читаем выделенный текст через Accessibility (`kAXSelectedTextAttribute`). Если он есть — сохраняем буфер обмена, кладём исправленный текст, жмём Cmd+V, возвращаем буфер.
- **Перекодировка:** таблица соответствия клавиш ЙЦУКЕН ↔ QWERTY (включая заглавные и знаки). Направление определяем по самому тексту: больше латиницы → в русский, иначе → в английский.
- **Автозапуск:** `SMAppService.mainApp.register()` (macOS 13+).
- **Хранение настроек:** `UserDefaults` (только вкл/выкл и автозапуск).

## Структура
```
LangSwitch/
  Sources/
    main.swift            — запуск приложения
    AppDelegate.swift     — иконка и меню
    KeyMonitor.swift      — перехват клавиш, двойной Shift, буфер слова
    InputSwitcher.swift   — смена RU/EN, текущий язык
    LayoutConverter.swift — таблица ЙЦУКЕН↔QWERTY
    TextFixer.swift       — исправление слова и выделения
  Resources/Info.plist
  build.sh                — сборка в LangSwitch.app одной командой
```

## Сборка и запуск
`./build.sh` → `swiftc` собирает `build/LangSwitch.app`. Переносим в «Программы», запускаем, даём разрешение «Универсальный доступ».
Нужны Xcode Command Line Tools (`xcode-select --install`). Без платного аккаунта разработчика — подписываем локально (`codesign -s -`).

## Проверка по constitution
- Лёгкость ✅ — один процесс, без окон, слушает только события.
- Без зависимостей ✅ — только системные фреймворки.
- Приватность ✅ — в памяти только последнее слово, ничего не пишем.
- Не ломать ввод ✅ — защищённый ввод (`IsSecureEventInputEnabled`) пропускаем; если выделение не прочиталось — только смена языка.
- Нюанс: после каждой пересборки macOS может «забыть» разрешение Универсального доступа (из-за локальной подписи) — придётся включить галочку заново. Это ограничение бесплатной подписи, не ошибка.
