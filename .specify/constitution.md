# LangSwitch — правила проекта

1. **Лёгкость.** Программа живёт в строке меню, почти не ест память и процессор, не мешает работать.
2. **Без лишних зависимостей.** Только Swift + системные библиотеки macOS. Никаких сторонних пакетов.
3. **Приватность.** Нажатия клавиш никуда не отправляются и не сохраняются на диск. В памяти держим только последнее слово.
4. **Не ломать ввод.** Если что-то пошло не так — лучше ничего не сделать, чем испортить текст. Поля паролей не трогаем.
5. **Проверка на живом Маке** перед сдачей каждого сценария.

**Стек:** Swift, AppKit, сборка одной командой `swiftc` (или `swift build`) в готовое `LangSwitch.app`. macOS 13+.
